# Getting Started with dbt and Semantic Views using Apache Ossie

Build a dbt star schema on TPC-H data, export dbt semantic layer metrics as an Apache Ossie (`0.1.1`) document during `dbt build`, and publish them as a native Snowflake Semantic View using `SYSTEM$CREATE_SEMANTIC_VIEW_FROM_OSSIE_YAML`.
